# LumaRoom · Evergreen website #17

Content: 15 original room-lighting guides; 2 interactive client-side planning/calculation tools; About, Contact, Privacy, Terms, Editorial and Sources pages. Responsive static HTML/CSS/JS.

## Deployment
1. Upload the **contents** of this ZIP to your GitHub repository's root.
2. Import the repository on Vercel as a static Other framework project; no build command required.
3. This package currently uses the **assumed** domain `https://lumaroom.my.id` in canonical links, sitemap.xml and robots.txt. If your actual domain differs, replace `https://lumaroom.my.id` globally in all HTML files plus robots.txt and sitemap.xml **before submitting to Search Console or AdSense**.
4. Point your domain at Vercel and verify homepage, article routes, `/ads.txt`, `/sitemap.xml`, contact email, tool interactions and mobile navigation.
5. Submit the actual domain as a property to Google Search Console and submit `/sitemap.xml`.
6. The AdSense publisher verification script is installed once in the head of each HTML page: `ca-pub-9692973918767107`. The `ads.txt` publisher ID also matches. This is for ownership/monetization readiness and does **not** guarantee approval or ad delivery.
7. Contact: `rafliraflu@gmail.com`.
8. The privacy statement describes Google AdSense technology but **no cookie consent banner is implemented**. Evaluate whether an approved CMP is required for your visitor regions and ad-serving setup before enabling personalized ads. Adapt policies to actual operations if you add analytics, tracking, forms or partners.
9. Editorial ownership is stated as 'LumaRoom Editorial' without inventing a human author, credentials or physical office. Add verified operator identity and original photos or tested examples where appropriate before submitting to AdSense.

## Quality checks
- Test the lighting plan and LED calculator on mobile and desktop.
- Each article is original educational editorial text and references the public source directory. Verify technical claims and local electrical norms before publication.
- Do not mistake any article-count target for an official AdSense requirement. Reviews remain at Google's discretion.
